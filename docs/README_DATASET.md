# Retail Enterprise BI Control Tower Dataset

Synthetic corporate-level retail dataset for Power BI and Tableau.

## Size
- Customers: 50,000
- Stores: 120
- Products: 1,800
- Orders raw: 130,250
- Order lines: 303,124
- Returns: 22,734
- Inventory snapshots: 720,000
- Marketing campaigns: 900

## Intentional raw data issues
- Duplicate records in orders and customers
- Missing discount percentages in order_details
- Unknown campaign IDs in orders
- Inconsistent product category capitalization
- Missing preferred contact values
- Online orders with no physical store

Use raw files for your project. Clean_reference files exist only for validation.
